# MT5連携

## 目的

常用しているExness版MT5の有効証拠金と、ハイリキ（Hyperliquid）の口座の残高を取得し、ドル円レートで円換算してFX口座残高へ反映します。どちらの額にも、その時点の含み益・含み損が含まれます。

`FX口座の金額 = (Exnessの有効証拠金 + ハイリキの残高) × ドル円レート`

## 使用するMT5

- MT5本体: `C:\Program Files\MetaTrader 5 EXNESS\terminal64.exe`
- 口座通貨: 米ドル
- ドル円の銘柄: 口座内から自動判定（現在は`USDJPYm`）

MT5に現在ログインしている口座のうち、本番口座だけを使用します。MT5が返す口座の種類が本番口座であることを、金額の取得前に確認します。口座番号やパスワードを家計簿側へ保存せず、家計簿の画面での追加の入力も不要です。

デモ口座・コンテスト口座・種類を確認できない口座では送信を見送ります。現在の金額と最終更新時刻は変更せず、0円に置き換えません。本番口座へ戻すと次の自動取得で更新を再開します。本番口座であれば口座番号による限定は行いません。

## ハイリキの残高

ハイリキの公開の問い合わせ窓口（`https://api.hyperliquid.xyz/info`）へ、口座のアドレスを指定して残高を読みます。秘密の鍵は使わず、注文・入金・出金も行いません。

口座のアドレスは、パソコンの`.env.local`に`HYPERLIQUID_ACCOUNT_ADDRESS=0x…`として書きます。このファイルはGitへ登録しません。書いていない場合はハイリキを足さず、Exnessの額だけを送信します。アドレスの形が正しくない場合は送信しません。

残高の数え方は、取得のたびに口座の種類（`userAbstraction`）を確かめて分けます。

| 口座の種類 | 数え方 |
| --- | --- |
| 統合口座（`unifiedAccount`）・`portfolioMargin` | 現物のUSDCの合計（`spotClearinghouseState`の`total`）だけ。先物の口座の額はここから割り当てた分なので足しません。足すと二重に数えます。 |
| 別々の口座（`default`・`disabled`） | 現物のUSDCの合計 ＋ 無期限先物の口座の額（`clearinghouseState`の`accountValue`） |
| それ以外（`dexAbstraction`など） | 数え方を確かめていないため、送信しません。 |

2026年10月28日時点の利用者の口座は統合口座です。USDC以外の現物（HYPEなど）は数えません。持っている場合は、動作記録にその旨だけを残します。

同じパソコンで動くコピーBOTと問い合わせの上限（1分あたり重さ1200）を分け合うため、1回の取得で問い合わせるのは2回（別々の口座なら3回）だけです。やり直しはしません。

### ハイリキを読めなかった時

**その回は、Exnessの分も含めて送信ごと見送ります。** 前回のハイリキの額は使いません。

- 現在の金額と最終更新時刻は変わらず、合計が急に減ることはありません。
- 保存される金額は、いつもExnessとハイリキを同じ時刻に読んだ組み合わせになります。古いハイリキの額が残り続けることもありません。
- 次の正時に、両方を読み直して更新を再開します。
- 問い合わせが混み合っている（429）場合は、その回を「見送り」として扱います。接続できない・答えを読み取れない・口座の種類が対応外の場合は「失敗」として動作記録に残します。どちらも送信しません。
- デモ口座などでMT5の送信を見送る回は、ハイリキへ問い合わせません。

## 換算方法

ドル円の売値と買値の中間値を換算レートとして使用します。Exnessとハイリキに同じレートを使います。

`円換算後の金額 = (Exnessのドル建て有効証拠金 + ハイリキのドル建て残高) × ドル円レート`

計算結果は1円単位に丸めます。相場が休止している時間は、MT5から取得できる直近の価格を使用します。

## 自動実行

Windowsのタスク名は`kakeibo MT5 balance sync`です。

- 日本時間の毎正時に現在の有効証拠金とハイリキの残高を更新
- 午前4時分だけ午前3時59分へ置き換え、日別記録との同時実行を防止
- 午前3時59分の金額を、午前4時に行う前日分の日別記録へ反映
- 1日24回取得し、パソコンを使用できない時間の取得は行わず、次の指定時刻に更新
- デモ口座などの場合や、ハイリキを読めない場合は、その回の取得・送信を見送り、保存済みの金額を維持

送信処理は画面を表示しない状態で実行します。動作記録は`%LOCALAPPDATA%\kakeibo\mt5-sync.log`へ保存しますが、残高・口座のアドレス・秘密情報は記録しません。

## 保存する情報

- 元のドル建て有効証拠金（Exness）
- 元のドル建て残高（ハイリキ。足していない回は空）
- 使用したドル円レートと銘柄名
- 円換算後の合計金額
- MT5で価格を取得した日時
- Cloudflareが受信した日時

Cloudflareへの通信は暗号化し、既存の秘密情報で本人のパソコンからの送信であることを確認します。

## 動作の確認

`.venv-mt5\Scripts\python.exe -B -m unittest discover -s tools/mt5-sync -p test_*.py` で、次のことを確認します。

- 本番口座だけが送信されること、デモ・コンテスト・不明な種類・口座情報の取得失敗では送信されないこと。本番口座の0円は正しい金額として扱います。
- 統合口座では現物のUSDCだけを足し、先物の口座の額を足さないこと。別々の口座では両方を足すこと。
- 対応外の口座の種類・壊れた答え・接続の失敗・429では送信しないこと。429ではやり直さないこと。
- デモ口座の回はハイリキへ問い合わせないこと。
- 送信内容で、Exnessとハイリキの額が分かれていること。

Cloudflare側は`npm test`で、合計の円換算と、2つの額を分けて保存すること、正しくないハイリキの額を保存しないことを確認します。

試験では作り物の口座情報と答えを使い、実際のMT5・ハイリキ・保存先は変更しません。
