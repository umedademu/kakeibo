# MT5連携

## 目的

常用しているExness版MT5の有効証拠金を取得し、ドル円レートで円換算してFX口座残高へ反映します。有効証拠金には、その時点の含み益・含み損が含まれます。

## 使用するMT5

- MT5本体: `C:\Program Files\MetaTrader 5 EXNESS\terminal64.exe`
- 口座通貨: 米ドル
- ドル円の銘柄: 口座内から自動判定（現在は`USDJPYm`）

MT5に現在ログインしている口座のうち、本番口座だけを使用します。MT5が返す口座の種類が本番口座であることを、金額の取得前に確認します。口座番号やパスワードを家計簿側へ保存せず、家計簿の画面での追加の入力も不要です。

デモ口座・コンテスト口座・種類を確認できない口座では送信を見送ります。現在の金額と最終更新時刻は変更せず、0円に置き換えません。本番口座へ戻すと次の自動取得で更新を再開します。本番口座であれば口座番号による限定は行いません。

## 換算方法

ドル円の売値と買値の中間値を換算レートとして使用します。

`円換算後の有効証拠金 = ドル建て有効証拠金 × ドル円レート`

計算結果は1円単位に丸めます。相場が休止している時間は、MT5から取得できる直近の価格を使用します。

## 自動実行

Windowsのタスク名は`kakeibo MT5 balance sync`です。

- 日本時間の毎正時に現在の有効証拠金を更新
- 午前4時分だけ午前3時59分へ置き換え、日別記録との同時実行を防止
- 午前3時59分の金額を、午前4時に行う前日分の日別記録へ反映
- 1日24回取得し、パソコンを使用できない時間の取得は行わず、次の指定時刻に更新
- デモ口座などの場合は、その回の取得・送信を見送り、本番口座の金額を維持

送信処理は画面を表示しない状態で実行します。動作記録は`%LOCALAPPDATA%\kakeibo\mt5-sync.log`へ保存しますが、残高や秘密情報は記録しません。

## 保存する情報

- 元のドル建て有効証拠金
- 使用したドル円レートと銘柄名
- 円換算後の有効証拠金
- MT5で価格を取得した日時
- Cloudflareが受信した日時

Cloudflareへの通信は暗号化し、既存の秘密情報で本人のパソコンからの送信であることを確認します。

## 動作の確認

`.venv-mt5\Scripts\python.exe -B -m unittest discover -s tools/mt5-sync -p test_*.py` で、本番口座だけが送信されること、デモ・コンテスト・不明な種類・口座情報の取得失敗では送信されないことを確認します。本番口座の0円は正しい金額として扱います。試験では作り物の口座情報を使い、実際のMT5や保存先は変更しません。
