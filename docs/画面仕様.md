# 画面仕様

## アプリの目的

個人の資産状況を日々管理し、記録するための家計簿アプリです。

## トップページ

パソコンでは、現在の資産表示を画面左側、未来と過去の資産推移グラフを右側に、4対6の割合で表示します。右上に「未来30日間の資産推移」、右下に「過去30日間の資産推移」を配置します。スマートフォンなど横幅が狭い画面では、現在の資産表示、未来のグラフ、過去のグラフの順に上下へ並べます。

5項目の合計を「総資産」として一番上に表示します。その下に、次の5項目の残高を表示します。

- 財布
- PayPay
- PayPay銀行
- 貯玉
- FX口座

財布、PayPay、PayPay銀行は、通常時は金額だけを表示します。金額部分を押すと入力欄へ切り替わり、入力後に欄の外を押すかEnterキーを押すと自動保存します。保存ボタンは表示しません。保存した内容は共通のデータベースから読み込むため、パソコンとスマートフォンで同じ残高が表示されます。

貯玉は、収支管理アプリに保存された全店舗合計を円換算し、毎日午前4時に自動取得した金額と最終更新時刻を表示します。

FX口座は、常用しているMT5の含み益・含み損を含むドル建て有効証拠金をドル円レートで円換算し、日本時間の午前1時、3時59分、9時、13時、17時、21時に自動取得した金額と最終更新時刻を表示します。画面を開いたままでも、1分ごとにCloudflareへ保存済みの残高表示を読み込みます。この画面の再読み込みでは、MT5やドル円レートを取得しません。

過去の資産推移グラフは、毎日午前4時に確定した5項目の日別残高を合計し、過去30日分を折れ線で表示します。まだ日別記録がない場合は、記録がたまると表示される旨を案内します。

未来の資産推移グラフは、現在の総資産を基準に、登録済みの収入と固定費を予測する各月の日数で割った1日分を毎日加減し、未来30日分を折れ線で表示します。臨時収支や各残高の変動は予測に含めません。「表で見る」から、日付、1日分の収入、1日分の固定費、予想資産を一覧表示する`/forecast`へ移動できます。

## ログインページ

資産情報を本人だけが閲覧・変更できるように、パスワードによるログインを行います。

ログイン状態は30日間保持します。共用端末では、利用後にトップページのログアウトボタンを使用します。

## 更新情報ページ

`/updates`で機能追加や改善の履歴を表示します。

## 固定費ページ

トップページの「資産／固定費／収入」の切り替えから`/fixed-costs`を表示します。

固定費ごとに支払日、項目名、金額を入力して新規登録できます。新規追加部分は、3つの入力欄と追加ボタンだけを横1行で表示します。入力欄と編集欄は、支払日、項目名、金額の順に表示します。登録済み一覧には、支払日、摘要、金額の列見出しを表示し、支払日は「22日」のように日付だけを表示します。登録済みの固定費は編集ボタンから3項目を変更でき、一覧の一番下には固定費の合計額を表示します。

固定費は共通のデータベースから読み込むため、パソコンとスマートフォンで同じ内容が表示されます。

## 収入ページ

「資産／固定費／収入」の切り替えから`/incomes`を表示します。

着金日、摘要、金額の順で収入を入力し、新規追加できます。登録済み一覧にも着金日、摘要、金額の列見出しを表示し、着金日順に並べます。登録済みの収入は編集でき、一覧の一番下には収入の合計額を表示します。

収入は共通のデータベースから読み込むため、パソコンとスマートフォンで同じ内容が表示されます。
