# 画面仕様

## アプリの目的

個人の資産状況を日々管理し、記録するための家計簿アプリです。

## トップページ

パソコンでは、資産、固定費、収入、借金の管理内容を画面左側、未来と過去の資産推移グラフを右側に、4対6の割合で表示します。左側は一つの共通枠とし、枠の先頭に「資産／固定費／収入／借金」の切り替えを表示します。切り替えを選んだときは枠内の管理内容だけを入れ替え、右側のグラフはそのまま表示します。画面を広く使えるよう、管理画面にはkakeiboや「現在の残高」の見出し、自動記録に関する補足を表示しません。グラフは題名とグラフ本体だけの簡潔な表示にし、推移の線を細め、各日の丸印も小さく表示します。右上に未来、右下に過去の資産推移を配置し、それぞれ30日と90日を小さな切り替えで選べるようにします。左側が長い場合も右側は画面内に保ちます。スマートフォンなど横幅が狭い画面では、選択中の管理内容、未来のグラフ、過去のグラフの順に上下へ並べます。

5項目の合計を「総資産」として一番上に表示します。その下に、次の5項目の残高を表示します。

- 財布
- PayPay
- PayPay銀行
- 貯玉
- FX口座

残高一覧の下、更新情報の上に、小さな「借金を含める」トグルスイッチを表示します。スイッチを入れると、5項目の合計から借金ページに登録された借金合計を差し引き、画面上の総資産として表示します。差し引いた結果がマイナスの場合は、マイナス記号を付けた赤系の文字で表示します。スイッチの状態は同じブラウザ内に保存します。

このスイッチは資産画面の総資産表示だけに適用します。過去・未来の資産推移、未来予測の表、毎日午前4時の日別記録、個別の残高には、スイッチの状態にかかわらず借金を差し引く前の金額を使用します。

財布、PayPay、PayPay銀行は、通常時は金額だけを表示します。金額部分を押すと入力欄へ切り替わり、入力後に欄の外を押すかEnterキーを押すと自動保存します。保存ボタンは表示しません。保存した内容は共通のデータベースから読み込むため、パソコンとスマートフォンで同じ残高が表示されます。

貯玉は、収支管理アプリに保存された全店舗合計を円換算し、画面を開いたときと画面を開いている間の1分ごとに最新金額を直接取得して表示します。収支管理アプリへ接続できない場合は、家計簿に保存済みの直近の日別記録を代わりに表示し、最新額ではないことを案内します。

FX口座は、常用しているMT5の含み益・含み損を含むドル建て有効証拠金をドル円レートで円換算し、日本時間の毎正時に自動取得した金額と最終更新時刻を表示します。ただし、午前4時分は午前3時59分に取得し、午前4時の日別記録へ反映します。画面を開いたままでも、1分ごとにCloudflareへ保存済みの残高表示を読み込みます。この画面の再読み込みでは、MT5やドル円レートを取得しません。

過去の資産推移グラフは、毎日午前4時に確定した5項目の日別残高を合計し、過去30日分または90日分を折れ線で表示します。まだ日別記録がない場合は、記録がたまると表示される旨を案内します。「表で見る」から、記録済みの日付と総資産を同じ期間で確認できる`/history`へ移動できます。

未来の資産推移グラフは、現在の総資産を基準に、収入は項目ごとに選んだ反映方法、固定費は予測する各月の日数で割った1日分を使って未来30日分または90日分を計算します。収入の「一括」は着金日に全額を加え、「日割り」は各月の日数で割った金額を毎日加えます。臨時収支や各残高の変動は予測に含めません。「表で見る」から、日付、当日の収入、1日分の固定費、予想資産を同じ期間で一覧表示する`/forecast`へ移動できます。

## ログインページ

資産情報を本人だけが閲覧・変更できるように、パスワードによるログインを行います。

ログイン状態は30日間保持します。共用端末では、利用後に各管理画面の最下部にあるログアウトボタンを使用します。

## 更新情報ページ

`/updates`で機能追加や改善の履歴を表示します。

## 固定費ページ

左側の共通枠にある「資産／固定費／収入／借金」の切り替えから`/fixed-costs`を表示します。右側の資産推移グラフは表示したまま、左側だけを固定費の管理内容へ切り替えます。

固定費ごとに支払日、項目名、金額を入力して新規登録できます。新規追加部分は、パソコンでは3つの入力欄と追加ボタンだけを横1行で表示し、スマートフォンでは入力しやすいように2行で表示します。入力欄と編集欄は、支払日、項目名、金額の順に表示します。登録済み一覧には、支払日、摘要、金額の列見出しを表示し、支払日は「22日」のように日付だけを表示します。編集ボタンは表示せず、登録済みの行を押すと3項目の編集欄へ切り替わります。一覧の一番下には固定費の合計額を表示します。

固定費は共通のデータベースから読み込むため、パソコンとスマートフォンで同じ内容が表示されます。

## 収入ページ

左側の共通枠にある「資産／固定費／収入／借金」の切り替えから`/incomes`を表示します。右側の資産推移グラフは表示したまま、左側だけを収入の管理内容へ切り替えます。

着金日、反映方法、摘要、金額の順で収入を入力し、新規追加できます。反映方法は「一括」と「日割り」から選び、新規追加時は「一括」を初期値にします。新規追加部分は、パソコンでは横1行、スマートフォンでは2行で表示します。登録済み一覧にも着金日、その右隣の反映、摘要、金額の列見出しを表示し、着金日順に並べます。編集ボタンは表示せず、登録済みの行を押すと4項目の編集欄へ切り替わります。一覧の一番下には収入の合計額を表示します。

「一括」は着金日に全額を未来予測へ加えます。着金日がその月に存在しない場合は月末に加えます。「日割り」は着金日にかかわらず、月額をその月の日数で割って毎日加えます。登録済みの収入は、従来の予測結果を維持するため「日割り」として引き継ぎます。

収入は共通のデータベースから読み込むため、パソコンとスマートフォンで同じ内容が表示されます。

## 借金ページ

左側の共通枠にある「資産／固定費／収入／借金」の切り替えから`/debts`を表示します。右側の資産推移グラフは表示したまま、左側だけを借金の管理内容へ切り替えます。

摘要と金額を入力して借金を新規追加できます。固定費・収入とは異なり、日付の入力欄は表示しません。登録済み一覧にも摘要と金額の列見出しを表示します。編集ボタンは表示せず、登録済みの行を押すと摘要と金額の編集欄へ切り替わります。一覧の一番下には借金の合計額を表示します。

借金はCloudflareの共通データベースから読み込むため、パソコンとスマートフォンで同じ内容が表示されます。
