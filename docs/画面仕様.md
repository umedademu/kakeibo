# 画面仕様

## アプリの目的

個人の資産状況を日々管理し、記録するための家計簿アプリです。

## トップページ

5項目の合計を「総資産」として一番上に表示します。その下に、次の5項目の残高を表示します。

- 財布
- PayPay
- PayPay銀行
- 貯玉
- FX口座

財布、PayPay、PayPay銀行は残高を入力して保存できます。保存した内容は共通のデータベースから読み込むため、パソコンとスマートフォンで同じ残高が表示されます。

貯玉は、収支管理アプリに保存された全店舗合計を円換算し、毎日午前4時に自動取得した金額を表示します。

FX口座は、常用しているMT5のドル残高をドル円レートで円換算し、5分ごとに自動取得した金額を表示します。画面を開いたままでも、1分ごとに最新の残高表示を読み込みます。

## ログインページ

資産情報を本人だけが閲覧・変更できるように、パスワードによるログインを行います。

ログイン状態は30日間保持します。共用端末では、利用後にトップページのログアウトボタンを使用します。

## 更新情報ページ

`/updates`で機能追加や改善の履歴を表示します。
